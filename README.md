## Bálint Balázs

Software engineering student at FH Upper Austria in Hagenberg, currently a
software engineering intern at Dynatrace in Linz.

### AI security and LLM agents

At Dynatrace I work on security tooling for AI agent components: building
prototypes, getting them integrated, then validating that they hold up in
practice. My bachelor's thesis comes out of the same area, a security and
quality evaluation of agentic skills. A skill is the packaged set of
instructions and tool definitions an agent loads at runtime and then acts on,
which means a skill the agent trusts is also a skill that can talk it into
doing the wrong thing. The question I care about is how you judge one before
it ever runs.

I build agent tooling for my own workflow too: review subagents that read a
diff before I commit it, git hooks that stop secrets from leaving the machine,
and a validation harness that keeps the whole setup reproducible across
machines.
